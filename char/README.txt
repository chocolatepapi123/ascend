CHARACTER IMAGES
Drop .jpg files in this folder with these exact names. Anything missing is
skipped, so add as many or as few as you like. The character images change by
themselves from your stats; there is no button to switch them by hand.

SIZE AND FRAMING
Portrait 4:5, 800 x 1000 px. Full body, front view, same pale grey-blue
studio background. Head top near y=35, shoes bottom near y=960, figure centred.
Gear (shades, cap, chain, watch, tank) is placed from measured landmarks for
each image in index.html (the LM table). A NEW image you add with a build name
(lean_happy.jpg, strong_tired.jpg ...) uses the landmarks of its build, so keep
the head, neck and shoes where they are in that build's image.

BUILDS (body size, chosen by Power)
  lean.jpg      Power under 45
  fit.jpg       Power 45 to 69
  strong.jpg    Power 70 and up

MOODS (face; prefix with the build, e.g. fit_tired.jpg)
  <build>_happy.jpg      finished something today
  <build>_proud.jpg      3+ day streak
  <build>_stressed.jpg   Chill under 30
  <build>_tired.jpg      HP under 20
  Shipped: fit_happy, fit_proud, fit_stressed, fit_tired.
  Lean and strong show their plain image until you add their moods.

EMOTES (shown for about 3 seconds; gear is hidden on these)
  emote_wave.jpg         any task done
  emote_flex.jpg         Power task done
  emote_celebrate.jpg    level up
  emote_slump.jpg        slip-up logged
  Optional per build: strong_emote_flex.jpg, lean_emote_wave.jpg, etc.

GEAR LAYERS (generated, do not rename)
  gear_shoes_lean.png, gear_shoes_fit.png, gear_shoes_strong.png
      red sneakers recoloured from each build's own shoes
  shop_sneakers.png      the picture shown in the Shop and Wardrobe
If you replace lean/fit/strong with new images, the red sneaker layers will no
longer line up with them. Ask for the layers to be regenerated.
